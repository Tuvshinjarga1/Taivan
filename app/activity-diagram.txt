@startuml TaivanAppActivity

title Тайван Апп - AI эрүүл мэндийн дүгнэлт авах үйл явц

start

:Нэвтрэх;

if (Нэвтэрсэн эсэх?) then (Тийм)
  :Google Fit холболт шалгах;
else (Үгүй)
  :Бүртгүүлэх/Нэвтрэх;
  :Google Fit холболт шалгах;
endif

if (Google Fit-тэй холбогдсон эсэх?) then (Тийм)
  :Эрүүл мэндийн мэдээлэл татах;
else (Үгүй)
  :Google Fit-тэй холбогдох;
  
  partition "Google Fit-тэй холбогдох процесс" {
    :Google Fit-ийн OAuth эрх шаардах;
    :Google Fit хуудас руу дамжуулах;
    :Хэрэглэгч Google бүртгэлээр нэвтрэх;
    
    if (Хэрэглэгч эрх олгох?) then (Тийм)
      :Эрх олголтын кодыг буцаах;
      :Эрх кодыг OAuth токен болгох;
      :Токен хадгалах;
      :Google Fit-тэй холбогдсон төлөвт шилжих;
    else (Үгүй)
      :Эрх татгалзсан алдаа буцаах;
      :Google Fit-тэй холбогдоогүй төлөвт үлдэх;
    endif
  }
  
  if (Google холболт амжилттай?) then (Тийм)
    :Эрүүл мэндийн мэдээлэл татах;
  else (Үгүй)
    :Холболтын алдааг харуулах;
    :Хянах самбар;
    stop
  endif
endif

:Эрүүл мэндийн мэдээлэл харуулах;
:Хянах самбар;
:AI Эрүүл мэндийн дүгнэлт хэсэг;

:Дүгнэлт гаргах товч дарах;
:Эрүүл мэндийн өгөгдөл шинжлэх дуудлага эхлүүлэх;
:Ачааллаж байгааг харуулах;
:AI үйлчилгээ руу хүсэлт илгээх;

if (AI хүсэлт амжилттай?) then (Тийм)
  :AI дүгнэлт хүлээн авах;
  :AI Эрүүл мэндийн дүгнэлт харуулах;
  :Хэрэглэгч зөвлөгөөг харах;
else (Үгүй)
  :Алдааны мессеж харуулах;
  :AI Эрүүл мэндийн дүгнэлт хэсэг;
  :Дүгнэлт гаргах товч дарах;
endif

stop

@enduml

title Тайван Апп - Чихрийн шижин таамаглах үйл явц

start

:Эрүүл мэндийн хянах самбар руу орох;
:Чихрийн шижингийн эрсдэлийн үнэлгээ хэсэг руу орох;

:Үнэлгээний мэдээллийг оруулах;
:Насаа оруулах;
:Хүйсээ сонгох;
:Биеийн жинг оруулах;
:Өндрийг оруулах;
:Гэр бүлийн түүхийг оруулах;
:Хоолны дадлыг оруулах;
:Биеийн идэвхийг оруулах;

:Үнэлгээ хийх товч дарах;

:Өгөгдлийг шалгах;

if (Өгөгдөл хүчинтэй?) then (Тийм)
  :Өгөгдлийг боловсруулах;
  :Эрсдэлийн оноог тооцоолох;
  
  if (Өндөр эрсдэлтэй?) then (Тийм)
    :Өндөр эрсдэлийн үр дүн харуулах;
    :Яаралтай эмчид хандахыг зөвлөх;
  elseif (Дунд эрсдэлтэй?) then (Тийм)
    :Дунд эрсдэлийн үр дүн харуулах;
    :Эмчид хандах зөвлөгөө өгөх;
  else (Бага эрсдэлтэй)
    :Бага эрсдэлийн үр дүн харуулах;
    :Эрүүл амьдралын хэв маягийн зөвлөгөө өгөх;
  endif
  
  :Эрсдэлийг бууруулах зөвлөмжүүд харуулах;
  :Тайлан хадгалах;
  
else (Үгүй)
  :Алдааны мессеж харуулах;
  :Хуудсыг шинэчлэх;
endif

:Эрүүл мэндийн хянах самбар руу буцах сонголт;

stop

@startuml TaivanAppFoodCaloriesActivity

title Тайван Апп - Хоолны илчлэг тооцоолох үйл явц

start

:Хоолны шинжилгээний хуудас руу орох;

:Хоолны төрлөө сонгох;

fork
  :Хоолны зургаа оруулах;
  :Зургийн чанарыг шалгах;
  
  if (Зураг хүчинтэй?) then (Тийм)
    :Зургийг AI шинжилгээ рүү илгээх;
    :Зураг дээрх хоолыг таних;
  else (Үгүй)
    :Дахин зураг оруулахыг хүсэх;
  endif
fork again
  :Хоолны нэрээ оруулах;
  :Порцын хэмжээг оруулах;
  :Орцуудыг жагсаах;
end fork

:Хоолны мэдээллийг боловсруулах;
:Калори тооцоолох;
:Тэжээллэг чанарын задаргааг тооцоолох (уураг, өөх тос, нүүрс ус);

:Үр дүнг харуулах;
:Өдөрт хэрэглэх зөвлөмж калорийн тоотой харьцуулан харуулах;

:Хооллолтын тэмдэглэлд хадгалах уу?;

if (Хадгалах уу?) then (Тийм)
  :Хэрэглэгчийн хооллолтын тэмдэглэлд хадгалах;
  :Хадгалсан баталгааг харуулах;
else (Үгүй)
  :Шинэ хоол шинжлэх сонголт харуулах;
endif

:Эрүүл хооллолтын зөвлөмж харуулах;

stop
